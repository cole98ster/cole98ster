## 🚀 Featured Projects

### [UltraSpeaker](https://github.com/cole98ster/ultraspeaker)
An ESP32-based ultrasonic directional speaker with motion/ultrasonic sensing and local web control. The project migrated from an Arduino-based design to ESP32, removing the need for an external waveform generator and simplifying the driver circuit.

### [MarketPulse](https://github.com/cole98ster/MarketPulse)
A full-stack trading-analytics platform featuring a watchlist, trade journal, news/economic-calendar view, chat service, and behavioural bias-detection API. Built with TypeScript, Python, Node.js, and Express.
